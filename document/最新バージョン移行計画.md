# Empire of Breakwaters 最新バージョン移行計画

作成日: 2026-06-14  
対象Mod: `Empire-of-Breakwaters`  
現行宣言: `descriptor.mod` の `supported_version="1.15.*"`  
参照文書:

- `document/NCNS Compatibility and Feature Guide　JP.md`
- `document/TAOG 互換性および機能ガイド　JP.md`

## 目的

`Empire of Breakwaters` を 1.15 系対応状態から、NCNS/TAOG 以後の最新HOI4仕様へ段階的に移行する。最優先は「起動・新規ゲーム開始・主要国家プレイがクラッシュしないこと」であり、その後に新機能の統合、バランス再調整、コンテンツ拡張を行う。

最新の厳密な `supported_version` は、移行着手時点のインストール済みバニラ `descriptor.mod` またはランチャー表示で確定する。計画上は NCNS と TAOG の仕様を含む最新版を対象とする。

## 現状診断

### 既存Mod構成

- `descriptor.mod` は `supported_version="1.15.*"`。
- `replace_path` が広い。特に `history/states`、`history/general`、`history/countries`、`history/units`、`events`、`map/strategicregions` はバニラ更新の取り込み漏れが即クラッシュや大規模不整合に直結する。
- `common/factions/` は既に存在し、NCNS系の陣営テンプレート、ルール、マニフェストらしき構造が入っている。
- `common/factions/goals/faction_manifests.txt` は大量の `collection:` 参照を使っているが、現状のMod側に `common/collections/` は存在しない。
- `common/doctrines/` は存在しない。新ドクトリン体系はバニラ依存、または未移植状態とみなす。
- `common/units/`、`common/technologies/`、`common/buildings/` は存在しない。TAOG/NCNSで追加された支援中隊、HQ、艦長、石炭・電力、海軍建物、装備・技術は主にバニラ側に依存する構成。
- `history/general/generic_advisors.txt` を `replace_path="history/general"` で置換しているため、TAOGで必須になる `history/general/taog_hq_template.txt` 取り込み漏れが最重要リスク。
- `map/terrain` は `replace_path` されているが、現状確認範囲ではMod内に `map/terrain` ディレクトリが見当たらない。NCNSの制海権仕様では地形・海域関連データの取り込み確認が必要。
- `events/VLA.txt` は `focus_progress` を使用しており、NCNS/TAOG後のフォーカス進捗・インレイ機能と相性確認が必要。

### 移行上の最重要リスク

1. `history/general` 置換によるHQテンプレート欠落
   - TAOG文書では、全国家にHQテンプレートがない場合CTDの可能性がある。
   - 最優先でバニラ最新版の `taog_hq_template.txt` 相当をModへ取り込む。

2. `history/states` と `map/strategicregions` の全面置換
   - NCNSの石炭・電力、戦略的ロケーション、ステートカテゴリ、制海権、海域・気候・地形の変更を取り込まないと、経済、建設、海軍AI、UI表示が破綻しやすい。

3. `common/factions` と `collection:` の整合性
   - 既存の陣営目標がバニラまたはMod側のコレクションに依存している。
   - `common/collections/` を持たないまま独自の陣営マニフェストを入れる場合、最新版バニラのコレクションIDと一致しているか検証が必要。

4. 新ドクトリン体系
   - `common/doctrines/` がないためクラッシュリスクは比較的低いが、国家方針・イベント・アイデアが旧ドクトリン効果や旧トリガーを前提にしている場合、報酬やAI挙動が劣化する。

5. 動的フォーカスアイコンとアビリティ構文
   - TAOG文書では旧式の動的フォーカスアイコン構文と旧式アビリティ一時バフ構文は機能しないとされている。
   - 全国家方針、アビリティ、GUI連携を検索して置換する。

## 移行方針

### 基本戦略

- まず最新版バニラとの差分を吸収し、起動安定性を確保する。
- その後、NCNS/TAOGの新機能を「必須互換」「ゲーム体験改善」「将来拡張」に分けて導入する。
- 既存の独自コンテンツは維持するが、バニラの大規模更新ファイルを丸ごと古い版で上書きしない。
- `replace_path` は必要性を再評価する。全面置換が不要なものは、可能なら通常マージまたは最小置換へ移す。

### フェーズ分け

| フェーズ | 目的 | 完了条件 |
| --- | --- | --- |
| 0 | ベースライン固定 | 現行ブランチ、バニラ最新版、ログ取得方法を確定 |
| 1 | CTD回避 | 起動、新規ゲーム開始、主要タグ選択が通る |
| 2 | 構文互換 | エラーログの旧構文・未定義ID・欠落ファイルを解消 |
| 3 | システム統合 | NCNS/TAOGの必須データをMod設計に合わせて反映 |
| 4 | コンテンツ調整 | 国家方針、陣営、海軍、支援中隊、HQ、艦長をプレイ可能品質へ調整 |
| 5 | QA | 1936/1939開始、主要国家、AI観戦、セーブロードを検証 |

## フェーズ5: `replace_path` 再設計

### 方針

今の `replace_path` は古いバニラファイルを広範囲に上書きするため、最新版移行で最も危険な設計になっている。移行中にすべてを外す必要はないが、次の優先度で縮小を検討する。

### 優先して見直すもの

1. `history/general`
   - HQテンプレート欠落がCTDに直結する。
   - 最小ファイル追加で済むなら維持、そうでなければ置換解除を検討。

2. `history/states`
   - 独自マップ・独自ステートがあるため置換解除は難しい。
   - ただし最新版バニラの新項目を取り込む専用マージ手順が必要。

3. `map/strategicregions`
   - 独自マップに必要なら維持。
   - NCNSの海軍・制海権変更を全戦略地域へ反映する。

4. `common/on_actions`
   - `00_on_actions.txt` と `05_lar_on_actions.txt` を置換しているため、最新版バニラのon_action追加を失いやすい。
   - 可能なら独自on_actionを `EoB_on_actions.txt` に寄せ、バニラファイル置換を避ける。

5. `common/scripted_effects`、`common/national_focus`、`common/decisions`
   - 国家方針や独自イベントとの絡みが大きい。
   - 置換解除はリスクがあるため、まず最新版バニラ差分を取り込んでから検討する。

## 検証計画

### 起動検証

- ランチャーでMod単体を有効化。
- 1936開始画面まで到達。
- 1939開始画面まで到達。
- 主要国家選択でCTDしない。
- `error.log` を保存し、未定義ID、未知トリガー、未知エフェクト、欠落GFX、欠落localisationを分類する。

### プレイ検証

最低限の対象国家:

- 日本: NCNSの東アジア更新、海軍、艦長、国家方針影響が大きい。
- 中国 / 中共: NCNSの中国更新、内戦イベント、陣営・コレクション影響が大きい。
- フィリピン: NCNS対象国であり、海軍・植民地・太平洋関連確認に向く。
- オーストラリア / シャム / インドネシア: TAOG対象地域であり、HQと新支援中隊の影響が大きい。
- 英国 / 米国 / ドイツ / ソ連: 主要システム回帰確認。
- EOB独自主要タグ: 独自コンテンツの破綻確認。

検証項目:

- 国家方針を3から5個進める。
- 陣営作成・加入・目標進捗を確認。
- 師団テンプレートを編集する。
- 将軍HQを配備・撤退する。
- 海軍任務を割り当てる。
- 艦長・勲章が出る戦闘を確認する。
- 工場・資源・電力・石炭表示を確認する。
- セーブ・ロードを1回行う。

### AI観戦

- 1936開始から1年観戦。
- 1936開始から1940年まで高速観戦。
- AIが海軍建造、師団設計、HQ配備、陣営目標、資源輸入で詰まらないか確認する。

## 作業順序の推奨

1. `descriptor.mod` は触らず、最新版バニラ差分を取得する。
2. `history/general` とHQテンプレートを先に直す。
3. `history/states`、`map/strategicregions`、地形・制海権を直す。
4. 起動してCTDを潰す。
5. 動的フォーカスアイコン、アビリティ、非推奨エフェクトを直す。
6. `common/factions` と `common/collections` の整合性を直す。
7. ドクトリン、石炭・電力、海軍、艦長、支援中隊を順に統合する。
8. `replace_path` の縮小可否を決める。
9. 1936/1939と主要国家でQAする。
10. 最後に `supported_version` を最新版へ更新する。

## 完了判定

次の条件を満たした時点で、最新版移行の第一段階を完了とする。

- `supported_version` を最新版に更新してもランチャー警告以外の問題がない。
- Mod単体で1936/1939開始が可能。
- 主要対象国家で初日CTDがない。
- エラーログに未定義の必須データ、未知トリガー、未知エフェクト、欠落HQテンプレートがない。
- 陣営、国家方針、師団デザイナー、HQ、海軍任務、資源・電力UIが最低限機能する。
- 1年AI観戦で停止・CTDしない。

## 注意事項

- NCNS/TAOGの新機能はDLCロックの有無が混在する。DLCなし環境でもクラッシュしない分岐を優先する。
- バニラファイルを古いまま丸ごと置換している箇所は、起動できても新機能が無効化される可能性がある。
- `common/factions` は一部導入済みに見えるため、二重定義やバニラID上書きの有無を必ず確認する。
- 独自マップ・独自ステートがあるため、ステートと戦略地域は単純なバニラ上書きではなく、Mod差分を保ったマージが必要。
